On the server, from the geoARK_Docker repo root:

    unzip geoark_incoming_older_2026-11-13.zip -d deploy/          # or: python3 -m zipfile -e geoark_incoming_older_2026-11-13.zip deploy/
    cd deploy
    sha256sum -c incoming/MANIFEST.sha256 | grep -v ': OK$'    # prints nothing if every file is intact
    make replay-dry        # read it before running it
    make replay

Folders land in deploy/incoming/<name>/. Do not edit, re-save or re-zip files inside: replay checks each
against the ledger (etl/data_manifest.yaml) by sha256 and refuses any that differ.
dem3dep/raw (2.2 GB of source elevation tiles) is NOT included: replay reads only the two prepared files.
